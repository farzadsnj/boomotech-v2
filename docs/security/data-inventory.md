# BoomoTech personal and sensitive data inventory

Date: 11 October 2026
Scope: repository schema, forms, browser storage, email, logs, monitoring, backups and optional AI integration. Examples are synthetic or masked.

## Data minimisation conclusions

- Name, email, service, message and consent are required for the current request workflow.
- Phone is operationally useful but should become optional if the owner confirms email-only follow-up is sufficient. No automatic removal is made here.
- Internal notes are justified only for service operations; the administrator UI must continue to keep them out of customer and AI views.
- Raw IP/user-agent collection is inherited from Better Auth and infrastructure. The application security-event helper deliberately does not duplicate it.
- No payment-card field, national identifier, date of birth, location tracking or public file upload exists.
